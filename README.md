# Planto 🌱

A simple iOS app that helps you take care of your plants and reminds you when it's time to water them.

## Features

- Add plants with name, room, light, watering days, and water amount
- Daily tracker to check off the plants you watered
- Progress message that updates as you complete reminders
- "All Done" screen when every plant is watered
- Edit or delete a plant reminder
- Local notifications to remind you to water your plants

## Screens

- **Start**: welcome screen with the Set Plant Reminder button
- **Tracker**: list of plants with a progress bar
- **Set Reminder**: add, edit, or delete a plant reminder

## Built With

- Swift
- SwiftUI
- UserNotifications

## How to Run

1. Clone the repository
2. Open `plants.xcodeproj` in Xcode
3. Choose an iPhone simulator
4. Press Run (⌘R)
